# RAGOps v1.2.0

## English

Publishes the current RAGOps package after the OpenAI Plugin Directory launch. It includes the dependency-free deterministic and statistical release-gate core, the credential-free customer-support demonstration, and skills-only plugin metadata for supported AI directories. PyPI publication uses a release-only GitHub Actions workflow with OIDC Trusted Publishing.

## Tiếng Việt

Phát hành package RAGOps hiện tại sau khi ra mắt trên OpenAI Plugin Directory. Phiên bản gồm core release gate xác định/thống kê không phụ thuộc dependency, demo customer support không cần credential và metadata plugin dạng skills-only cho các AI directory được hỗ trợ. PyPI được phát hành bằng workflow GitHub Actions chỉ dành cho release với OIDC Trusted Publishing.

## 日本語
