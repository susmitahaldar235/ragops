# RAGOps v2.0.1

RAGOps 2.0.1 republishes the complete 2.0 feature set under a usable PyPI version. PyPI permanently reserved the deleted `2.0.0` distribution filenames, so `2.0.1` is the first installable PyPI release of the 2.0 line.

The release preserves the offline, provider-independent evaluation contract, content-addressed evidence bundles, slice and distribution gates, calibration, trace graphs, dataset leakage controls, CI-native outputs, portable adapters, blind review governance, optional API/workbench, and deterministic ChatGPT skills-only plugin bundle introduced in 2.0.0.

The credential-free flagship demo intentionally blocks a synthetic regression: citation coverage `1.0 -> 0.5`, citation precision `1.0 -> 0.5`, and lexical groundedness `1.0 -> 0.6`. This is reproducible synthetic evidence, not production adoption evidence.

## Compatibility

- Python 3.11 or newer.
- Dependency-free core remains offline.
- Existing scenario 0.1/0.2 and trace 0.3 readers remain supported.
- FastAPI/Uvicorn remain optional through `ragops[api]`.
- No hosted MCP connector is included.
