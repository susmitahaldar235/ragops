# RAGOps v2.0.0

RAGOps 2.0 strengthens the offline release contract without changing the existing 1.x readers or CLI paths. It adds verifiable evidence bundles, slice/distribution policy gates, calibration, trace graphs, dataset leakage controls, CI-native outputs, portable vendor import profiles, blind review governance, and a packaged optional API/workbench.

The credential-free flagship demo intentionally blocks a synthetic regression: citation coverage `1.0 -> 0.5`, citation precision `1.0 -> 0.5`, and lexical groundedness `1.0 -> 0.6`. This is reproducible synthetic evidence, not production adoption evidence.

Release artifacts include wheel, sdist, CycloneDX SBOM, SHA-256 manifest, local validation evidence, and a deterministic ChatGPT skills-only plugin ZIP. Publication to GitHub, PyPI, and the ChatGPT directory are independently verified states.

## Compatibility

- Python 3.11 or newer.
- Dependency-free core remains offline.
- Existing scenario 0.1/0.2 and trace 0.3 readers remain supported.
- FastAPI/Uvicorn remain optional through `ragops[api]`.
- No hosted MCP connector is included.
